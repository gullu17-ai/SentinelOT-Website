# Redesign review

15 November 2026

## Existing website

The original homepage put an industrial context photograph ahead of the product evidence. The primary Watch Demo action led to an unavailable-recording notice. Product, protocol scope, architecture, hardware, research and team content shared one long page. The older logo and missing-contact notice no longer matched the user's updated brand and supplied team details.

## Product Studio changes

The new homepage leads with the operator benefit and genuine dashboard screenshots, then explains local evidence, capabilities and intended applications. Product contains the detailed evidence gallery, protocol boundaries, passive architecture and optional hardware concept. Research explains validation and the roadmap. About contains the approved team roles and direct email links.

The downloadable two-page brief summarizes current capabilities and development limits for customers and investors. It does not present plans as completed work.

## Deliberate boundaries

- No fabricated video, customer references, portraits, metrics or vulnerability screenshot.
- Hardware is a concept; target-hardware deployment remains unverified.
- Historical screenshots retain their original interface, branding and dates.
- The website is a static export, isolated from the monitoring system.
- User requested no GitHub push or publication.
